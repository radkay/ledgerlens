# Decisions

| ID | Decision | Options considered and rationale | Ron: |
|---|---|---|---|
| D-001 | Feature PRs squash into dev. The release PR merges with a merge commit. | Squash keeps one increment per feature PR. A release merge retains those increments and ancestry. | |
| D-002 | GitHub native rulesets, CODEOWNERS, auto-merge and automatic head-branch deletion. | Native checks and draft holds keep setup and review within GitHub. Dev accepts green PRs without requiring the head to be up to date. Protected branch deletion restrictions preserve dev after a release. | |

Enable the repository integration gate after both environments are ready. | |
